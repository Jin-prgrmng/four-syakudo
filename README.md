# four-syakudo

名義・順序・間隔・比例の4種類の尺度の違いを理解するための、高校生向けの授業用ゲーム。

生徒は「フローチャート」「4択クイズ」「60秒仕分け」の3つのモードを順に遊び、項目がどの尺度にあたるかを判断できるようになることを目指す。仕様は [docs/design.md](docs/design.md) にまとめてある。

## 動かし方

```
npm start   # http://localhost:8000 を開く（Python 3 が必要）
npm test    # 問題データと採点ロジックを検査する（Node.js 18 以上）
```

## 問題を追加・修正する

問題項目は [data/items.json](data/items.json) にある。項目を編集したあとは `npm test` を実行して、形式の誤りがないことを確認する。
