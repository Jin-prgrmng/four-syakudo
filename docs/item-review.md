# 問題項目の精査（2026-10-01）

## 目的と判定基準

試用した人から「答えが一つに定まらない項目がある」と指摘を受けたため、`data/items.json` の全57項目を見直した。判定基準は、項目名と例の値だけを見た人が、Stevens (1946) の4分類に沿って考えたときに、答えが一つに決まるかどうかである。

答えが割れる原因は、次の3つに分けられる。

- 何を測っているかが二通りに読める（例：靴のサイズは「足の長さ」とも「サイズの区分」とも読める）。
- 理論上の分類と、実際の扱われ方が食い違う（例：通知表の評定は順序尺度だが、平均を計算して使うことが多い）。
- 例の値そのものに、分類を崩す要素が入っている（例：和暦の例が元号をまたいでいた）。

答えが割れる項目は、次のいずれかで扱った。「議論あり」（`contested: true`）にした項目は、4択クイズでだけ出題し、正解に準じる答え（`alternatives`）を選んでも正解として数える。フローチャートと60秒仕分けには出さない。

## 確認したうえで変更しなかった項目

次の項目は、別の答えを主張することもできる。ただし、教科書の標準的な分類がはっきりしていること、項目名と例で測り方が決まっていることから、答えは一つに定まると判断した。友人の指摘がこの中の項目だった場合は、個別に見直す。

| ID | 項目 | 正解 | 出てきそうな別の答えと、変更しない理由 |
|---|---|---|---|
| n05 | その日の天気 | 名義 | 雲の量の順に並べられるという主張はありうる。しかし晴れ・雨・雪は種類の違いであり、雪と雨の間に上下はない |
| n07 | スポーツ選手の背番号 | 名義 | エースナンバーのように番号に意味を持たせる慣習はあるが、番号の大小で選手の上下は決まらない |
| n08 | 郵便番号 | 名義 | 番号はおおまかに地域順に振られているが、番号の大小や差に意味はない |
| o02 | 地震の震度 | 順序 | 震度のもとになる計測震度は連続した値だが、例は「5弱」を含む震度階級なので段階として読める |
| o05 | 料理の満足度 | 順序 | 議論ありにした5段階回答（c02）と同じく、間隔とみなして平均を取る扱いもある。ただし数字ではなく言葉の選択肢なので、平均を取る発想が出にくいと判断して残した。指摘がこの項目なら議論ありに移す |
| o12 | ラーメン店の辛さの段階 | 順序 | 「2倍」「3倍」と量で表す店もある。しかし項目名を「段階」とし、例を「1辛, 2辛」としているので、店が決めた段階と読める |
| i03 | 時刻 | 間隔 | 0時からの経過時間とみれば比例になる。しかし「午前6時」「正午」のような時刻そのものは、教科書でも間隔尺度の代表例である |

## 前提知識がないと解けない項目（2026-10-01 追記）

試用した人から、一部の項目は少し専門的な知識がないと解けないという指摘も受けた。この種の項目は、尺度の考え方ではなく、項目についての知識を問うことになってしまう。ただし、項目そのものは尺度を学ぶうえで役に立つものが多い。そこで削除はせず、解くのに必要な前提知識を `hint` として1行で添え、カードの例の下に表示することにした。ヒントには、尺度の判断（「0 は何もないことを表す」など）は直接書かず、項目が何を表すかだけを書く。

| ID | 項目 | 足りなかった知識 | 添えたヒント |
|---|---|---|---|
| o02 | 地震の震度 | 震度がどういう値か | 揺れの強さを 0〜7 の段階で表したもの |
| o10 | 鉱物のモース硬度 | 硬度の決め方 | 鉱物どうしをこすり、傷がつかない方を硬いとした番号 |
| o11 | ガチャのレアリティ | ゲームの用語 | ゲームのくじで出るキャラクターなどの、珍しさの等級 |
| n14 | 推しのメンバーカラー | アイドル文化の用語 | アイドルグループで、メンバーごとに決められた色 |
| i04 | 気温（華氏 °F） | 華氏の 0 がどの温度か | アメリカなどで使う温度の単位。0°F はおよそ −18℃ |
| i05 | 偏差値 | 偏差値の作り方 | テストの点数を、平均が 50 になるように換算した値 |
| r10 | 絶対温度（ケルビン K） | 0 K の意味 | 0 K（−273.15℃）は、これ以上は下がらない最低の温度 |
| r13 | 唐辛子の辛さ（スコヴィル値） | スコヴィル値が何を測るか | 唐辛子に含まれる辛さの成分の量をもとにした値 |
| r14 | RPG のキャラクターの HP | ゲームの用語 | ゲームのキャラクターの体力を表す数値 |

あわせて、4択クイズで解答したあとは選択肢の箱を低くし、「分かれ目」の説明を1文に縮めた。全56項目それぞれに誤答した場合を幅 360px・高さ 640px の画面で表示し、どの項目でもスクロールせずに解説まで読めることを確認した。
